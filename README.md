# BSCS 7th Semester – Mid-Term Subject Explorer

An interactive study site for the mid-term exam, covering three subjects:

| Subject | Lectures | Topics |
|---|---|---|
| Database Systems | Lecture 1, Lecture 2, Chapter 3 | 44 |
| Entrepreneurship | Lectures 1–5 | 37 |
| Data Mining | Introduction & KDD, Linear Regression, Lecture 6 (Decision Trees / ID3), Neural Networks | 30 |

Each topic has full notes, exam-focus points, an **"Explain it simply"** section, key diagrams and the original **source slides/pages** it was written from.

**Made by Syed Talha Aliyan Ali Shah** · Department of IT, Thal University

## Open it
- Online: enable **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / root), then open the link GitHub shows.
- Offline: download the repository and open `index.html` in a browser.

## Files
- `index.html` – the site
- `data/` – topic notes (`db.js`, `en.js`, `dm.js`), simple explanations (`simple.js`) and source-slide mapping (`sources.js`)
- `img/` – photos, `img/fig/` key diagrams, `img/src/` source slides and pages from the lecture files
